# Efectos de sonido

Esta carpeta se llena sola al correr `bash install.sh` (copia whoosh-short, pop, sparkle, click, click-soft e
impact-bass-1 desde `~/.claude/skills/video-edit/assets/template/assets/sfx`).

Son de Pixabay (Pixabay Content License): puedes usarlos dentro de tus videos, pero no redistribuir los archivos
sueltos. Por eso no vienen en este repositorio. Para usar otros, pon un `.mp3` con el mismo nombre.
